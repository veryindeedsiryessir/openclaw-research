# OpenClaw video notes – Team of Agents setup

- Source: https://youtu.be/bzWI3Dil9Ig?si=uZTUqwLd26XUwabW
- Date captured: 2026-02-27

## Core points

1. OpenClaw is most useful as an always-on multi-agent operating model.
2. Use a dedicated machine, not a personal daily-driver laptop.
3. Separate credentials/access like onboarding employees (least privilege).
4. Separate API billing from personal subscriptions; optimize model usage by role.
5. Chat alone is insufficient at scale; custom dashboard/mission-control layer is key.
6. Main use-cases: backlog execution, glue work, reporting, and trend detection.
7. Security and operational safeguards are mandatory.

## Relevance to our setup

- Confirms our current direction: R21 dashboard + Mission Control + role/task automation.
- Reinforces need for strong observability, scheduling, and guardrails.
- Supports current roadmap: weekly briefing, risk register, source-grounded workflows.

## Suggested actions

- Keep improving Mission Control as source of truth.
- Enforce access boundaries for each workflow.
- Track token cost by workflow/agent role.
- Continue moving from ad-hoc chat to structured task pipelines.
